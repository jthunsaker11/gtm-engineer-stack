# Your Offering

## What you do
Wozcode is an intelligent routing and context-optimization layer that sits between developer
IDEs (Claude Code, Cursor) and Anthropic's Claude API. It cuts per-developer Claude spend by
30 to 50% with a 5-minute plugin install and zero code changes.

## Structural moat
Wozcode sits between the IDE and the API, so it sees every request and can route and
compress context without the developer changing how they work. It is model-agnostic: the
same layer optimizes spend regardless of which Claude model the developer calls.

## Reference customer
A European telecom with 15,000 developers on Claude ran a Wozcode pilot and saw a meaningful
per-developer cost reduction. Carry the source and framing forward when citing it; do not
inflate the pilot into a signed enterprise-wide result.

## How you describe it in icebreakers
"That is the layer Wozcode sits at, between the IDE and the Claude API, cutting per-developer
spend without a code change." (adapt to the trigger)

## When to mention your ICP qualifier
Drop the qualifier when the trigger context already establishes the space (the recipient
runs an engineering org already scaling Claude). Keep it when reaching someone whose AI
infrastructure stage is unclear from context.
