# Setup guides

One-time setup steps that some skills need before their `--execute` or write paths work. Each guide is self-contained: prerequisites, a walkthrough, testing, and troubleshooting. Skills run in their default read-or-plan mode without any of this; you only need a guide when you want the execute path it describes.

## Guides

- [Claygent column: sales-motion buying-signal check](claygent-buying-signal-column.md) - build the Clay Claygent web-research column and inbound webhook that `audience-builder --execute` uses to confirm a company runs an outbound sales motion worth prospecting. Required only for `--execute` with the app-side buying-signal check; plan mode and the WebSearch fallback need nothing here.

More guides will be added as Tier 1 skills land.
